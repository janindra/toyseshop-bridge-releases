# ToysEshop Most – instalačky

Veřejné releasy aplikace ToysEshop Most (zdrojový kód je v soukromém repozitáři). Aplikace si odsud sama hledá nové verze.

Stáhněte DMG z [Releases](../../releases): `…-arm64.dmg` pro Mac s Apple Silicon, druhý pro Intel. Při prvním spuštění: pravým tlačítkem → Otevřít (aplikace není notarizovaná).
